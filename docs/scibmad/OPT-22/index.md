# OPT-22 — `copy!` into a `VectorField` drops the spin part, so `log` never corrects its spin generator

NonlinearNormalForm's `copy!` omits a `VectorField` destination's quaternion, its spin part, so copies and typed conversions lose spin and `log` never receives its spin correction. For a constant rotation generated by (0, 0.1, 0.2, 0.05), `log` returns its unchanged initial guess (−0.02614, 0.09913, 0.1983, 0.04956), so the defining round trip exp(log M) = M fails; copying the quaternion restores the analytic generator to round-off. An orbit-dependent test has spin error 0.172 for generator size 0.15, and the same guard also breaks in-place `real!` and `imag!`. Checked orbital logs remain accurate, and no measured SciBmad output consumes the spin generator.

    # OPT-22: `copy!` into a `VectorField` drops the spin part, so `log` never corrects its spin
    # generator
    #
    # NonlinearNormalForm's `copy!` omits a `VectorField` destination's quaternion, its spin part, so
    # copies and typed conversions lose spin and `log` never receives its spin correction. For a
    # constant rotation generated by (0, 0.1, 0.2, 0.05), `log` returns its unchanged initial guess
    # (−0.02614, 0.09913, 0.1983, 0.04956), so the defining round trip exp(log M) = M fails; copying the
    # quaternion restores the analytic generator to round-off. An orbit-dependent test has spin error
    # 0.172 for generator size 0.15, and the same guard also breaks in-place `real!` and `imag!`.
    # Checked orbital logs remain accurate, and no measured SciBmad output consumes the spin generator.
    #
    # Test 1 copies a `VectorField` with spin and reads the copy's quaternion. Test 2 takes `log` of an
    # orbital identity with the constant spin rotation q = exp(f), f = (0.1, 0.2, 0.05), whose exact
    # generator has spin part f, and checks exp(log M) = M through `exp`, which does not use `copy!`;
    # test 3 takes `log` of M = exp(F₀, I) for an orbit-dependent spin generator F₀ on `Descriptor(4,
    # 4)`. All three are then rerun with `copy!` redefined to copy the quaternion into a `VectorField`
    # as well.
    using SciBmad
    const NNF = NonlinearNormalForm
    const TI = SciBmad.TI
    r3(x) = round(x, sigdigits=3)
    nq(A, B) = maximum(GTPSA.normTPS(getfield(A.q, k) - getfield(B.q, k)) for k in 1:4)
    x, p = vars(Descriptor(2, 4)); z = 0 * x
    F = VectorField(v=[p, -x], q=[z, 0.1 + x, z, z])
    println("test 1: F.q.q1 = ", scalar(F.q.q1), ";  copy(F).q.q1 = ", scalar(copy(F).q.q1), "  (expected 0.1)")
    # Test 2: exp of a pure quaternion f is (cos|f|, sin|f| f/|f|), so log of this map must have spin
    # part f.
    f = [0.1, 0.2, 0.05]; nf = sqrt(sum(abs2, f))
    Mc = DAMap(v=[x, p], q=[cos(nf) + z, (sin(nf) / nf * f .+ z)...], nv=2)
    Fc = VectorField(v=[z, z], q=[z, (f .+ z)...])
    X1, P1, X2, P2 = vars(Descriptor(4, 4)); Z = 0 * X1
    F0 = 0.1 * VectorField(v=[P1 + 0.3X1^2 + 0.2X2*P2, -X1 + 0.5P1^2, P2 - 0.4X1*X2, -X2 + 0.1X1^3],
                           q=[Z, 0.2 + 0.7X1 + 0.3P1*X2, 0.5 + 0.4P2 + 0.6X1^2, 0.1 + 0.8X2 - 0.5X1*P1])
    M0 = exp(F0, DAMap(v=[X1, P1, X2, P2], q=[1 + Z, Z, Z, Z], nv=4))
    function logs(label)
      Lc = log(Mc); L0 = log(M0)
      println(label, "test 2: |log(M).q - f| = ", r3(nq(Lc, Fc)), ", |exp(log M) - M| spin = ", r3(nq(exp(Lc, one(Mc)), Mc)),
              ";  test 3: |log(M).q - F0.q| = ", r3(nq(L0, F0)), " (|F0.q| = ", r3(maximum(GTPSA.normTPS(getfield(F0.q, k)) for k in 1:4)),
              "), orbital ", r3(maximum(GTPSA.normTPS(L0.v[i] - F0.v[i]) for i in 1:4)))
      return nq(Lc, Fc)
    end
    e = logs("")
    # Recheck: copy! also copies q whenever the destination has one; upstream copies it only into a
    # TaylorMap.
    @eval NNF function copy!(m::Union{TaylorMap,VectorField}, m1::Union{TaylorMap,VectorField})
      checkstates(m, m1)
      if m1 isa TaylorMap && m isa TaylorMap
        m.v0 .= m1.v0
      end
      nv = nvars(m)
      foreach((xi, x1i)->TI.copy_tps!(xi, x1i), view(m.v, 1:nv), m1.v)
      if !isnothing(m.q)
        foreach((qi, q1i)->TI.copy_tps!(qi, q1i), m.q, m1.q)
      end
      if m isa TaylorMap && !isnothing(m.s) && m1 isa TaylorMap
        m.s .= m1.s
      end
      return m
    end
    println("recheck, copy! also copying q into a VectorField: copy(F).q.q1 = ", scalar(copy(F).q.q1))
    logs("recheck: ")
    println(e > 1e-10 ? "DEFECT REPRODUCED" : "NOT REPRODUCED")
