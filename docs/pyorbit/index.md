# PyORBIT

Verified defects in [PyORBIT](https://github.com/PyORBIT-Collaboration/PyORBIT3) ([source](https://github.com/PyORBIT-Collaboration/PyORBIT3)).
Each entry links to its reproducer, the models that found and confirmed it, and any upstream issue or pull request.
Machine-readable: [defects.json](defects.json).
Tags are explained in [Methodology](../methodology.md#tags).

## Running the reproducers

1. Build PyORBIT3 from source; the build needs a C++ compiler and FFTW. In a clone of the
   repository, run `pip install --config-settings=setup-args=-DUSE_MPI=none .`.
2. Run `python <ID>.py` with `OMP_NUM_THREADS=1`, one script per process.

Some reproducers also need: cpymad, scipy.

A script that needs more than this states it in a `Setup:` paragraph of its description.
Each entry's *Last reproduced* names the release or commit its reproducer last ran on, and its
provenance table gives the build of every run.
